# Правила разработки 1С

Стандарты кодирования, принципы и инструкции для разработки на платформе «1С:Предприятие 8.3» (8.3.18 и новее).

## С чего начать

1. Прочитайте [стандарт кодирования](./standards/README.md) — хотя бы разделы «Коротко» в каждой главе.
2. Подключите [шаблоны текста](./templates/README.md) в конфигураторе.
3. Держите под рукой [чек-лист ревью](./standards/review_checklist.md).

## Содержание

| Раздел | Что внутри |
|---|---|
| [**Стандарт кодирования**](./standards/README.md) | Обязательные правила: имена, методы, запросы, формы, доработка типовых, расширения. **Обязательно к прочтению.** |
| [Статьи](./articles/README.md) | Почему правила такие: принципы программирования, объектный стиль имён, правила разработки, модификация форм расширениями. |
| [Инструкции](./guides/README.md) | Как сделать: процесс разработки; дальше — очистка кэша, Jenkins и другое. |
| [Шаблоны текста](./templates/README.md) | Шаблоны для конфигуратора: модули, методы, метки доработок. |

## На что стоит обратить внимание

- [**Универсальные инструменты 1С**](https://github.com/cpr1c/tools_ui_1c) — расширение с набором инструментов разработчика для управляемого приложения 8.3: консоль запросов, редактор объектов, консоль кода, HTTP-клиент, инструменты для XML и JSON и многое другое. Лицензия GPL-3.0.
- [**Навыки Claude Code для 1С**](https://github.com/Desko77/claude-code-skills-1c) — набор навыков и правил для разработки на 1С с помощью ИИ-ассистента Claude Code: создание, изменение и анализ объектов конфигурации из выгрузки в XML. Лицензия MIT.
