# Методы БСП

[↑ Оглавление](./README.md)

> Шпаргалка по самым нужным методам Библиотеки стандартных подсистем: что уже написано и где это лежит. Дополняет правила [4.1.3](./04_methods.md#41-декомпозиция) и [4.5.2](./04_methods.md#45-прочее).

**Коротко**

- Прежде чем писать служебный метод, ищем его здесь, а затем — поиском по конфигурации.
- Вызываем только методы из области `ПрограммныйИнтерфейс`. Служебные и устаревшие — нет.
- Страница сверена с БСП 3.1.12. Перед использованием метода проверяем, что он есть в нашей версии.

## Как пользоваться

- **Версия.** Имена и параметры сверены с исходными текстами БСП 3.1.12.335. В конфигурации версия может быть другой — её возвращает `СтандартныеПодсистемыСервер.ВерсияБиблиотеки()`. В старых версиях части методов нет, у части другие параметры.
- **Состав.** Подсистемы БСП внедряются выборочно. Модуля `РаботаСПочтовымиСообщениями` или `ОценкаПроизводительности` в конкретной конфигурации может не быть.
- **Проверка.** Открываем общий модуль в конфигураторе и убеждаемся, что метод лежит в области `ПрограммныйИнтерфейс`, а не в `СлужебныйПрограммныйИнтерфейс` или `УстаревшиеПроцедурыИФункции`. Там же — полное описание параметров.
- **Параметры.** В таблицах показаны обязательные и часто используемые параметры. Необязательные опущены.
- **Контекст.** Модуль без суффикса — серверный, `…Клиент` — клиентский, `…КлиентСервер` доступен везде. С клиента серверный метод вызывается через свой серверный метод формы (см. [9.1](./09_forms.md#91-вызовы-сервера)).

## Чтение данных по ссылке

Модуль `ОбщегоНазначения`. Основа правила [15.3](./15_performance.md#правила): реквизиты ссылки через точку не читаем.

| Метод | Что делает |
|---|---|
| `ЗначениеРеквизитаОбъекта(Ссылка, ИмяРеквизита)` | Значение одного реквизита. |
| `ЗначенияРеквизитовОбъекта(Ссылка, Реквизиты)` | Структура со значениями нескольких реквизитов. `Реквизиты` — строка через запятую, массив или структура. |
| `ЗначениеРеквизитаОбъектов(МассивСсылок, ИмяРеквизита)` | Соответствие «ссылка → значение реквизита» для набора ссылок. Один запрос на все ссылки. |
| `ЗначенияРеквизитовОбъектов(Ссылки, Реквизиты)` | Соответствие «ссылка → структура реквизитов» для набора ссылок. |
| `СсылкаСуществует(ПроверяемаяСсылка)` | Истина, если объект физически есть в базе. |
| `ПредопределенныйЭлемент(ПолноеИмяПредопределенного)` | Ссылка на предопределённый элемент по имени вида `"Справочник.ВидыКонтактнойИнформации.EmailПользователя"`. Если элемента нет, возвращает `Неопределено`, а не падает. На клиенте — одноимённый метод `ОбщегоНазначенияКлиент`. |
| `ОбъектЯвляетсяГруппой(Объект)` | Истина, если элемент справочника или плана видов характеристик — группа. |
| `ПредметСтрокой(СсылкаНаПредмет)` | Представление ссылки для сообщений и писем. |

У всех четырёх методов чтения реквизитов есть параметр `ВыбратьРазрешенные`. При значении `Истина` чтение идёт с учётом прав пользователя.

<details><summary>Пример</summary>

```bsl
// ❌ Плохо: два обращения к базе, каждое читает объект целиком
ИНН = Контрагент.ИНН;
КПП = Контрагент.КПП;

// ✅ Хорошо: один запрос, только нужные поля
КонтрагентРеквизиты = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Контрагент, "ИНН, КПП");

// ✅ Хорошо: для набора ссылок — один запрос вместо запроса в цикле
КонтрагентыИНН = ОбщегоНазначения.ЗначениеРеквизитаОбъектов(Контрагенты, "ИНН");
Для Каждого КонтрагентыЭлемент Из Контрагенты Цикл
	ИНН = КонтрагентыИНН[КонтрагентыЭлемент];
	// ...
КонецЦикла;
```

</details>

## Сообщения, ошибки, проверки

| Метод | Что делает |
|---|---|
| `ОбщегоНазначения.СообщитьПользователю(ТекстСообщенияПользователю, КлючДанных, Поле, ПутьКДанным, Отказ)` | Сообщение с привязкой к полю формы. Устанавливает `Отказ` в Истина. |
| `ОбщегоНазначенияКлиент.СообщитьПользователю(ТекстСообщенияПользователю, КлючДанных, Поле, ПутьКДанным, Отказ)` | То же на клиенте. |
| `СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке(ИнформацияОбОшибке)` | Показывает пользователю ошибку, перехваченную на клиенте или полученную из длительной операции. |
| `ОбщегоНазначения.КодОсновногоЯзыка()` | Код основного языка базы. Нужен в `НСтр()` для строк, которые записываются в базу и в журнал регистрации. |
| `ЖурналРегистрацииКлиент.ДобавитьСообщениеДляЖурналаРегистрации(ИмяСобытия, ПредставлениеУровня, Комментарий)` | Запись в журнал регистрации из клиентского кода. |
| `ОбщегоНазначенияКлиентСервер.ПроверитьПараметр(ИмяПроцедурыИлиФункции, ИмяПараметра, ЗначениеПараметра, ОжидаемыеТипы)` | Вызывает исключение, если тип параметра не тот. Для методов программного интерфейса. |
| `ОбщегоНазначенияКлиентСервер.Проверить(Условие, Сообщение)` | Вызывает исключение, если условие ложно. Самодиагностика кода. |

На сервере в журнал регистрации пишем методом платформы `ЗаписьЖурналаРегистрации()`. Серверный `ЖурналРегистрации.ДобавитьСообщениеДляЖурналаРегистрации()` лежит в служебном интерфейсе БСП, его не вызываем.

## Строки

Модуль `СтроковыеФункцииКлиентСервер`, если не указано иное.

| Метод | Что делает |
|---|---|
| `ТолькоЦифрыВСтроке(Значение)` | Истина, если в строке только цифры. |
| `ДополнитьСтроку(Значение, ДлинаСтроки, Символ, Режим)` | Дополняет строку символами слева или справа до нужной длины. |
| `СтрокаВЧисло(Значение)` | Число или `Неопределено`, если строка не число. Замена `Попытка` при разборе чужих данных ([7.1.2](./07_exceptions.md#71-попытка-и-исключения)). |
| `СтрокаВДату(Значение)` | Дата из строки или пустая дата. |
| `ЭтоУникальныйИдентификатор(Значение)` | Истина, если строка — уникальный идентификатор. |
| `ПараметрыИзСтроки(СтрокаПараметров, Разделитель)` | Структура из строки вида `"Ключ1=Значение1;Ключ2=Значение2"`. |
| `ВставитьПараметрыВСтроку(ШаблонСтроки, Параметры)` | Подставляет в шаблон именованные параметры в квадратных скобках из структуры. |
| `СтрокаСЧисломДляЛюбогоЯзыка(Шаблон, Число)` | Строка с числом и правильной формой слова: «1 день», «2 дня», «5 дней». |
| `ИзвлечьТекстИзHTML(ИсходныйТекст)` | Текст без тегов HTML. |
| `ЗаменитьОдниСимволыДругими(ЗаменяемыеСимволы, Значение, СимволыЗамены)` | Посимвольная замена. |
| `СтроковыеФункции.СтрокаЛатиницей(Значение)` | Транслитерация. Серверный модуль. |
| `СтроковыеФункции.ФорматированнаяСтрока(ШаблонСтроки, Параметр1, …)` | Форматированная строка из шаблона с разметкой: ссылки, жирный шрифт, цвет. Серверный модуль. |

Для подстановки по номерам параметров и для разбора строки есть методы платформы — `СтрШаблон()`, `СтрРазделить()`, `СтрСоединить()`. Их и используем вместо `ПодставитьПараметрыВСтроку()` и `РазложитьСтрокуВМассивПодстрок()`.

## Метаданные и типы

Модуль `ОбщегоНазначения`, если не указано иное.

| Метод | Что делает |
|---|---|
| `МенеджерОбъектаПоСсылке(Ссылка)` | Менеджер объекта по ссылке. |
| `МенеджерОбъектаПоПолномуИмени(ПолноеИмя)` | Менеджер объекта по имени вида `"Документ.ЗаказПокупателя"`. |
| `ИмяТаблицыПоСсылке(Ссылка)` | Полное имя объекта метаданных — для текста запроса и блокировок. |
| `ВидОбъектаПоСсылке(Ссылка)` | Вид объекта строкой: `"Справочник"`, `"Документ"`. |
| `ЗначениеСсылочногоТипа(Значение)` | Истина, если значение — ссылка. `ЭтоСсылка(ПроверяемыйТип)` — то же для типа. |
| `ЭтоДокумент(ОбъектМетаданных)` | Истина, если объект метаданных — документ. Есть `ЭтоСправочник` и `ЭтоРегистр`. |
| `ЕстьРеквизитОбъекта(ИмяРеквизита, МетаданныеОбъекта)` | Есть ли реквизит у объекта метаданных. Замена `Попытка` ([7.1.2](./07_exceptions.md#71-попытка-и-исключения)). |
| `ОбщегоНазначенияКлиентСервер.ЕстьРеквизитИлиСвойствоОбъекта(Объект, ИмяРеквизита)` | Есть ли свойство у произвольного объекта, без обращения к метаданным. |
| `ОписаниеТипаСтрока(ДлинаСтроки)` | Описание типов «строка» заданной длины. Есть `ОписаниеТипаЧисло` и `ОписаниеТипаДата`. |
| `ИдентификаторОбъектаМетаданных(ОписаниеОбъектаМетаданных)` | Ссылка на объект метаданных — чтобы хранить его в базе. |
| `ПодсистемаСуществует(ПолноеИмяПодсистемы)` | Истина, если подсистема есть в конфигурации. Используется вместе с `ОбщийМодуль()`. |
| `ОбщийМодуль(Имя)` | Ссылка на общий модуль по имени — для вызова необязательной подсистемы. |

<details><summary>Пример: вызов необязательной подсистемы</summary>

```bsl
Если ОбщегоНазначения.ПодсистемаСуществует("СтандартныеПодсистемы.РаботаСПочтовымиСообщениями") Тогда
	МодульПочта = ОбщегоНазначения.ОбщийМодуль("РаботаСПочтовымиСообщениями");
	ОтправкаДоступна = МодульПочта.ДоступнаОтправкаПисем();
КонецЕсли;
```

</details>

## Сериализация, настройки, пароли

Модуль `ОбщегоНазначения`.

| Метод | Что делает |
|---|---|
| `ЗначениеВСтрокуXML(Значение)` | Сериализует значение в строку XML. Обратно — `ЗначениеИзСтрокиXML(СтрокаXML)`. |
| `ЗначениеВJSON(Значение)` | Строка JSON. Обратно — `JSONВЗначение(Строка)`; объекты JSON по умолчанию читаются в соответствия. |
| `КонтрольнаяСуммаСтрокой(Данные)` | Контрольная сумма произвольных данных. |
| `ХранилищеОбщихНастроекСохранить(КлючОбъекта, КлючНастроек, Настройки)` | Сохраняет настройку пользователя. |
| `ХранилищеОбщихНастроекЗагрузить(КлючОбъекта, КлючНастроек, ЗначениеПоУмолчанию)` | Читает настройку пользователя. |
| `ЗаписатьДанныеВБезопасноеХранилище(Владелец, Данные, Ключ)` | Сохраняет пароль или другой секрет. Ключ по умолчанию — `"Пароль"`. |
| `ПрочитатьДанныеИзБезопасногоХранилища(Владелец, Ключи)` | Читает секрет. |
| `УдалитьДанныеИзБезопасногоХранилища(Владелец, Ключи)` | Удаляет секрет. |

Пароли, токены и ключи храним только в безопасном хранилище — не в реквизитах, константах и коде. Привилегированный режим вызывающий код устанавливает сам.

<details><summary>Пример</summary>

```bsl
// Владелец — ссылка на элемент настроек или уникальная строка с префиксом подсистемы
УстановитьПривилегированныйРежим(Истина);
ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище(НастройкаОбмена, Токен, "Токен");
УстановитьПривилегированныйРежим(Ложь);

УстановитьПривилегированныйРежим(Истина);
Токен = ОбщегоНазначения.ПрочитатьДанныеИзБезопасногоХранилища(НастройкаОбмена, "Токен");
УстановитьПривилегированныйРежим(Ложь);
```

</details>

## Пользователи и права

| Метод | Что делает |
|---|---|
| `Пользователи.ТекущийПользователь()` | Ссылка на текущего пользователя. На клиенте — `ПользователиКлиент.ТекущийПользователь()`. |
| `Пользователи.АвторизованныйПользователь()` | Пользователь, который вошёл в программу. |
| `Пользователи.ЭтоПолноправныйПользователь()` | Истина для администратора и в привилегированном режиме. |
| `Пользователи.РолиДоступны(ИменаРолей)` | Истина, если доступна хотя бы одна из ролей или пользователь полноправный. Вместо `РольДоступна()`. |
| `УправлениеДоступом.ЧтениеРазрешено(ОписаниеДанных)` | Может ли пользователь читать объект с учётом ограничений на уровне записей. |
| `УправлениеДоступом.ИзменениеРазрешено(ОписаниеДанных)` | Может ли пользователь изменить объект. |

Эти методы помогают выполнить правило [4.5.3](./04_methods.md#45-прочее): доработка работает под пользовательскими правами.

## Длительные операции

Всё, что выполняется дольше пары секунд, запускаем фоновым заданием — форма остаётся отзывчивой, а пользователь видит ожидание и может отменить операцию.

| Метод | Что делает |
|---|---|
| `ДлительныеОперации.ПараметрыВыполненияФункции(ИдентификаторФормы)` | Параметры запуска. |
| `ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения, ИмяФункции, Параметр1, …)` | Запускает экспортную функцию в фоне. До семи параметров. Результат функции попадает во временное хранилище. |
| `ДлительныеОперации.ВыполнитьПроцедуру(ПараметрыВыполнения, ИмяПроцедуры, Параметр1, …)` | То же для процедуры. |
| `ДлительныеОперации.СообщитьПрогресс(Процент, Текст)` | Сообщает о ходе выполнения из фонового задания. |
| `ДлительныеОперацииКлиент.ПараметрыОжидания(ФормаВладелец)` | Параметры окна ожидания. |
| `ДлительныеОперацииКлиент.ОжидатьЗавершение(ДлительнаяОперация, ОповещениеОЗавершении, ПараметрыОжидания)` | Ждёт завершения и вызывает оповещение. |

<details><summary>Пример</summary>

```bsl
&НаКлиенте
Процедура ЦеныПересчитать(Команда)

	ДлительнаяОперация = ЦеныПересчитатьНаСервере();
	Оповещение = Новый ОписаниеОповещения("ЦеныПересчитатьЗавершение", ЭтотОбъект);
	ОжиданиеПараметры = ДлительныеОперацииКлиент.ПараметрыОжидания(ЭтотОбъект);
	ДлительныеОперацииКлиент.ОжидатьЗавершение(ДлительнаяОперация, Оповещение, ОжиданиеПараметры);

КонецПроцедуры

// Показывает результат пересчёта цен.
&НаКлиенте
Процедура ЦеныПересчитатьЗавершение(Результат, ДополнительныеПараметры) Экспорт

	// Неопределено — пользователь отменил операцию
	Если Результат = Неопределено Тогда
		Возврат;
	КонецЕсли;

	Если Результат.Статус = "Ошибка" Тогда
		СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке(Результат.ИнформацияОбОшибке);
	Иначе
		ЦеныЗагрузитьНаСервере(Результат.АдресРезультата);
	КонецЕсли;

КонецПроцедуры

// Запускает пересчёт цен в фоновом задании.
&НаСервере
Функция ЦеныПересчитатьНаСервере()

	ВыполнениеПараметры = ДлительныеОперации.ПараметрыВыполненияФункции(УникальныйИдентификатор);
	Результат = ДлительныеОперации.ВыполнитьФункцию(ВыполнениеПараметры, "пр_Цены.Пересчитать",
		Объект.ВидЦены, Объект.Дата);

	Возврат Результат;

КонецФункции
```

</details>

Функция, которая выполняется в фоне, — экспортная функция общего модуля или модуля менеджера. Её параметры и результат должны быть сериализуемыми. Поле `ИнформацияОбОшибке` в результате есть в БСП 3.1.12; в старых версиях вместо него — `КраткоеПредставлениеОшибки` и `ПодробноеПредставлениеОшибки`.

## Файлы

| Метод | Что делает |
|---|---|
| `ФайловаяСистема.СоздатьВременныйКаталог()` | Создаёт временный каталог на сервере. Удалять — `УдалитьВременныйКаталог(Путь)`. |
| `ФайловаяСистема.УдалитьВременныйФайл(Путь)` | Удаляет временный файл. Если файл занят, пишет предупреждение в журнал регистрации и не падает. |
| `ФайловаяСистема.УникальноеИмяФайла(ИмяФайла)` | Имя файла, которого ещё нет в каталоге. |
| `ФайловаяСистемаКлиент.ЗагрузитьФайл(ОбработчикЗавершения, ПараметрыЗагрузки)` | Диалог выбора файла и помещение его во временное хранилище. Параметры — `ПараметрыЗагрузкиФайла()`. |
| `ФайловаяСистемаКлиент.СохранитьФайл(ОбработчикЗавершения, РасположениеФайла, ИмяФайла)` | Сохраняет файл из временного хранилища на компьютер пользователя. |
| `ФайловаяСистемаКлиент.ОткрытьФайл(РасположениеФайла)` | Открывает файл программой по умолчанию. |
| `ФайловаяСистемаКлиент.ОткрытьНавигационнуюСсылку(НавигационнаяСсылка)` | Открывает ссылку в браузере или в программе. |
| `ОбщегоНазначенияКлиентСервер.ДобавитьКонечныйРазделительПути(ПутьКаталога)` | Путь, который заканчивается разделителем. |
| `ОбщегоНазначенияКлиентСервер.РазложитьПолноеИмяФайла(ПолноеИмяФайла)` | Структура: путь, имя, расширение, имя без расширения. |
| `ОбщегоНазначенияКлиентСервер.ЗаменитьНедопустимыеСимволыВИмениФайла(ИмяФайла)` | Имя файла без запрещённых символов. |
| `РаботаСФайлами.ДвоичныеДанныеФайла(ПрисоединенныйФайл)` | Двоичные данные присоединённого файла. |
| `РаботаСФайлами.ДобавитьФайл(ПараметрыФайла, АдресФайлаВоВременномХранилище)` | Присоединяет файл к объекту. Параметры — `ПараметрыДобавленияФайла()`. |
| `ПолучениеФайловИзИнтернета.СкачатьФайлНаСервере(URL, ПараметрыПолучения)` | Скачивает файл с учётом настроек прокси. Возвращает структуру: `Статус`, `Путь`, `СообщениеОбОшибке`. |

Временные файлы, которые создал наш код, наш код и удаляет — в том числе при ошибке.
