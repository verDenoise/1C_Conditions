# Правила разработки 1С

Стандарты кодирования, принципы и практики разработки на платформе «1С:Предприятие 8.3» (8.3.18 и новее).

## Содержание

- [**Стандарты кодирования**](./standart/README.md) — обязательные правила написания кода. **Обязательно к прочтению.**
- [Статьи](./articles/README.md) — принципы программирования, правила разработки, объектный стиль имён, модификация форм расширениями.
- [Процесс разработки](./process/README.md) — схемы процесса от требований до релиза.
- [Шаблоны текста](./templates/README.md) — шаблоны для конфигуратора.

## На что стоит обратить внимание

- [**Универсальные инструменты 1С**](https://github.com/cpr1c/tools_ui_1c) — расширение с набором инструментов разработчика для управляемого приложения 8.3: консоль запросов, редактор объектов, консоль кода, HTTP-клиент, инструменты для XML и JSON и многое другое. Лицензия GPL-3.0.
- [**Навыки Claude Code для 1С**](https://github.com/Desko77/claude-code-skills-1c) — набор навыков и правил для разработки на 1С с помощью ИИ-ассистента Claude Code: создание, изменение и анализ объектов конфигурации из выгрузки в XML. Лицензия MIT.
