# 5. Переменные

[Оглавление](./README.md) | Назад: [4. Методы](./04_methods.md) | Далее: [6. Условия и циклы](./06_control_flow.md)

Имена переменных строятся по общим правилам из [2. Имена](./02_names.md).

## Правила

- **5.1** Имя переменной однозначно описывает её содержимое.
- **5.2** Каждая переменная используется только с одной целью. Переиспользовать переменную под другое значение запрещено.
- **5.3** Значения переменной не несут скрытого смысла. Если `ФайловКоличество` может быть равно `-1`, и это означает ошибку, — это скрытый смысл. Для ошибки заводится отдельная переменная или вызывается исключение.
- **5.4** Для стандартных ролей используются стандартные имена: `Отказ`, `СтандартнаяОбработка`, `Результат`, `Запрос`, `Выборка`.
- **5.5** Возвращаемое значение функции хранится в переменной `Результат`, которая инициализируется в начале функции (см. [4.3](./04_methods.md#43-функции)).
- **5.6** Счётчики и элементы циклов:
  - имя счётчика цикла `Для` заканчивается на `Индекс`, `Позиция` или `Номер`;
  - имя элемента цикла `Для Каждого` заканчивается на `Элемент`, для таблиц — на `Строка`;
  - во вложенных циклах имена отражают содержимое: `ТоварыИндекс`, `РеквизитыЭлемент`, `ДоговорыСтрока`. Без вложенности допустимы общие имена: `Индекс`, `Элемент`, `Строка`.
- **5.7** Булевы переменные называются утвердительно.
- **5.8** «Магические» числа и строки заменяются именованными значениями. Без имени допускаются только `0` и `1` в очевидном контексте (начало нумерации, приращение).
- **5.9** Переменная объявляется рядом с местом первого использования. Исключение — переменная результата функции.

Одна переменная — одна цель:

```bsl
// ❌ Плохо: «Текст» сначала хранит заголовок, потом — тело письма
Текст = ЗаказЗаголовок(Заказ);
Письмо.Тема = Текст;
Текст = ЗаказОписание(Заказ);
Письмо.Тексты.Добавить(Текст);

// ✅ Хорошо
ПисьмоТема = ЗаказЗаголовок(Заказ);
ПисьмоТекст = ЗаказОписание(Заказ);
Письмо.Тема = ПисьмоТема;
Письмо.Тексты.Добавить(ПисьмоТекст);
```

Скрытый смысл значения:

```bsl
// ❌ Плохо: -1 означает «ошибка чтения каталога»
ФайловКоличество = КаталогФайлыКоличество(Каталог);
Если ФайловКоличество = -1 Тогда
	// ...
КонецЕсли;

// ✅ Хорошо: признак ошибки отдельно от количества
Если пр_Каталог.Доступен(Каталог) Тогда
	ФайловКоличество = пр_Каталог.ФайлыКоличество(Каталог);
Иначе
	// ...
КонецЕсли;
```

Счётчики и элементы вложенных циклов:

```bsl
// ❌ Плохо: во вложенном цикле непонятно, где что
Для Каждого Элемент Из Заказы Цикл
	Для Каждого Строка Из Элемент.Товары Цикл
		// ...
	КонецЦикла;
КонецЦикла;

// ✅ Хорошо
Для Каждого ЗаказыЭлемент Из Заказы Цикл
	Для Каждого ТоварыСтрока Из ЗаказыЭлемент.Товары Цикл
		// ...
	КонецЦикла;
КонецЦикла;
```

Цикл по индексу:

```bsl
// ❌ Плохо: выход за границу коллекции — индексы коллекций начинаются с 0
Для Индекс = 0 По Товары.Количество() Цикл

// ✅ Хорошо
ТоварыГраница = Товары.Количество() - 1;
Для ТоварыИндекс = 0 По ТоварыГраница Цикл
```

Магические числа:

```bsl
// ❌ Плохо: что такое 86400 и 30?
Если ТекущаяДатаСеанса() - Документ.Дата > 86400 * 30 Тогда

// ✅ Хорошо
СекундВСутках = 86400;
СрокХраненияДней = 30;
Если ТекущаяДатаСеанса() - Документ.Дата > СекундВСутках * СрокХраненияДней Тогда
```

Утвердительные булевы переменные:

```bsl
// ❌ Плохо
НетОшибок = Истина;
Если НЕ НетОшибок Тогда

// ✅ Хорошо
ОшибкиЕсть = Ложь;
Если ОшибкиЕсть Тогда
```

## Пояснения и рекомендации

### Одна цель

Соблазн переиспользовать переменную, которая «уже отработала», появляется часто. Но тогда её имя подходит только к одной из ролей, а читатель должен отслеживать, какое значение в ней сейчас. Две переменные с точными именами понятнее одной с общим.

### Скрытый смысл

Когда разные значения переменной означают разные вещи (количество — если больше нуля, ошибку — если `-1`), это называют гибридным сопряжением. Такое поведение приходится описывать комментариями, и о нём легко забыть. Лучше, когда скрытых смыслов нет вовсе.

### Магические числа

Число `86400` в коде понятно не каждому, а `СекундВСутках` — каждому. Кроме того, именованное значение меняется в одном месте. Не стоит следовать правилу слепо: в формулах некоторые константы понятнее в числовой записи (`Радиус * 2`). Повторяющиеся по проекту значения выносятся в функции модуля с повторным использованием возвращаемых значений или в константы.

### Короткие имена

Стремление сокращать имена переменных — пережиток. Короткое удачное имя получается, если убрать лишние слова или подобрать точный синоним, а не сократить слова. Перечитайте код, который вы не видели полгода: имена, которые не понятны с первого взгляда, — сигнал изменить подход к их выбору.
