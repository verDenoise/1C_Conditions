# Шаблоны текста

Шаблоны текста для конфигуратора «1С:Предприятие 8.3»: [bsl.st](./bsl.st). Настоятельно рекомендуются к использованию — ускоряют написание кода и делают его единообразным (см. правила [3.2.2](../standart/03_modules.md#32-структура-модуля) и [11.2.1](../standart/11_comments.md#112-описания)).

Автор шаблонов — [shmalevoz](https://gitlab.com/bsl-env/rules/-/tree/main/templates). Актуальная версия — в его репозитории.

## Подключение

1. В параметрах конфигуратора («Сервис» → «Параметры», настройки модулей) включить автоматическую замену шаблонов.
2. Открыть окно настройки шаблонов текста.
3. Отключить стандартные шаблоны (при желании) и подключить файл `bsl.st`.

## Основные сокращения

Набираете сокращение, ставите пробел — сокращение заменяется текстом шаблона.

| Сокращение | Результат |
|---|---|
| `проц` | Процедура с шаблоном описания |
| `функ` | Функция с шаблоном описания и переменной `Результат` |
| `общиймодуль` | Новый общий модуль с областями |
| `модульформы` | Новый модуль формы с областями |
| `модульобъекта` | Новый модуль объекта с областями и инструкциями препроцессора |
| `модульменеджера` | Новый модуль менеджера с областями и инструкциями препроцессора |
| `/+`, `/*`, `/-` | Метки изменения типового кода `[+]`, `[*]`, `[-]` (см. [13.3](../standart/13_typical_changes.md#133-метки-изменений)) |

## Отключённые проверки BSL Language Server

Шаблоны модулей содержат комментарии, которые отключают часть стандартных проверок. Эти отступления признаны допустимыми:

- `EmptyRegion` — пустые области разрешены;
- `NonStandardRegion` — нестандартные области разрешены (в модулях форм);
- `NestedFunctionInParameters` — вызов функции в качестве параметра метода разрешён (но не глубже двух уровней, см. [4.1.7](../standart/04_methods.md#41-декомпозиция)).
