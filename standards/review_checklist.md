# Чек-лист ревью

[↑ Оглавление](./README.md)

Короткий список того, что проверяем на ревью. Каждый пункт ведёт к правилу, где есть подробности и примеры.

## Имена и структура

- [ ] Имена полные, без сокращений и частицы «Не», в объектном стиле ([2](./02_names.md))
- [ ] Нетиповые объекты и ключи `ДополнительныеСвойства` — с префиксом подсистемы ([2.1.8](./02_names.md#21-общие-правила))
- [ ] Суффиксы общих модулей — по таблице ([2.2.5](./02_names.md#22-объектный-стиль))
- [ ] Метод лежит в модуле своего объекта, логика — не в форме ([3.1](./03_modules.md#31-размещение-кода))
- [ ] Экспорт — только в интерфейсных областях, областей внутри методов нет ([3.2](./03_modules.md#32-структура-модуля))

## Методы и переменные

- [ ] Метод делает одно и помещается на экран ([4.1](./04_methods.md#41-декомпозиция))
- [ ] Нет дублей кода — в том числе с БСП и кодом коллег ([4.1.3](./04_methods.md#41-декомпозиция))
- [ ] У функции один `Возврат` в конце и `Результат`, заданный в начале ([4.3](./04_methods.md#43-функции))
- [ ] Входящие параметры не изменяются, при вызове сервера — `Знач` ([4.2](./04_methods.md#42-параметры))
- [ ] Обработчики записи учитывают `ОбменДанными.Загрузка` ([4.4](./04_methods.md#44-обработчики-событий-объектов))
- [ ] Одна переменная — одна цель, у магических чисел есть имена ([5](./05_variables.md))

## Логика

- [ ] Основной вариант — в `Если`, нет пустых веток и двойных отрицаний ([6.1](./06_control_flow.md#61-условия))
- [ ] Вложенность — не больше трёх уровней ([6.1.11](./06_control_flow.md#61-условия)), тело цикла короткое ([6.2](./06_control_flow.md#62-циклы))
- [ ] `Попытка` — только для небезопасных операций, ошибки не «проглатываются» ([7.1](./07_exceptions.md#71-попытка-и-исключения))
- [ ] Транзакция оформлена по шаблону, `ОтменитьТранзакцию()` — первой в `Исключение` ([7.2](./07_exceptions.md#72-транзакции))

## Запросы и производительность

- [ ] Нет соединений с подзапросами и виртуальными таблицами ([8.2.4](./08_queries.md#82-содержание))
- [ ] Отборы виртуальных таблиц — в параметрах ([8.2.5](./08_queries.md#82-содержание))
- [ ] Текст запроса — в отдельной функции, оформлен как в конструкторе ([8.1](./08_queries.md#81-оформление))
- [ ] Не больше одного вызова сервера на действие, по умолчанию — без контекста ([9.1](./09_forms.md#91-вызовы-сервера))
- [ ] Реквизиты ссылок не читаются через точку ([15.3](./15_performance.md#правила))

## Оформление

- [ ] У методов есть описания, у экспортных — полные ([11.2](./11_comments.md#112-описания))
- [ ] Нет закомментированного кода, подписей и TODO без задачи ([11.1](./11_comments.md#111-комментарии))
- [ ] Отступы — табуляцией, одна строка — один оператор, строки до 120 символов ([12.1](./12_formatting.md#121-общие-правила))
- [ ] Переносы — со знаком операции в начале строки ([12.4](./12_formatting.md#124-перенос-строк))

## Доработка типовых

- [ ] Всё, что можно, сделано расширением; новые хранимые данные — в конфигурации ([13.1](./13_typical_changes.md#131-общие-правила))
- [ ] Изменения типового кода — в метках `[+]`, `[*]`, `[-]` ([13.3](./13_typical_changes.md#133-метки-изменений))
- [ ] В расширении нет `&Вместо` без `ПродолжитьВызов()` ([14.3](./14_extensions.md#143-методы))
- [ ] Заимствованные формы пустые, изменения формы — кодом ([14.4](./14_extensions.md#144-формы))

## Хранилище

- [ ] Комментарий к помещению — `#<задача> <что изменилось>` ([16.4](./16_storage.md#правила))
