# Устаревшие правила

[↑ Оглавление](./README.md)

> Правила прежних редакций, которые больше не нужны в новых разработках, но могут пригодиться при сопровождении старых конфигураций и на старых версиях платформы.

## Обработчики оповещений — функциями

> **Устарело с платформы 8.3.18 (2020)**: появились асинхронные функции `Асинх` / `Ждать`.

**Было:** методы завершения асинхронных вызовов (обработчики `ОписаниеОповещения`) оформлялись функциями, возвращающими `Неопределено`. Так при недоступности оповещений обработчик можно было вызвать через `Вычислить`: `Выполнить` недоступен в мобильной платформе.

**Сейчас:** в новых разработках используются `Асинх` / `Ждать`. Обработчики `ОписаниеОповещения` — там, где они ещё нужны, — оформляются обычными процедурами.

```bsl
// Сейчас
&НаКлиенте
Асинх Процедура ЗаказУдалить(Команда)

	Ответ = Ждать ВопросАсинх(пр_ЗаказТексты.УдалениеВопрос(), РежимДиалогаВопрос.ДаНет);

	Если Ответ = КодВозвратаДиалога.Да Тогда
		ЗаказУдалитьНаСервере();
	КонецЕсли;

КонецПроцедуры
```

## Представление ошибок функциями глобального контекста

> **Устарело с платформы 8.3.17**: появился объект `ОбработкаОшибок`.

**Было:** для журнала регистрации — `ПодробноеПредставлениеОшибки(ИнформацияОбОшибке())`, для пользователя — `КраткоеПредставлениеОшибки(ИнформацияОбОшибке())`.

**Сейчас:** одноимённые функции глобального контекста считаются устаревшими, используются методы `ОбработкаОшибок` (см. [7.1.7](./07_exceptions.md#71-попытка-и-исключения)). На платформе ниже 8.3.17 прежнее правило действует.

## Поддержка обычного приложения

> **Актуально только для конфигураций, работающих в режиме обычного приложения.** Современные типовые конфигурации (ERP 2, УТ 11, БП 3.0, ЗУП 3 и др.) работают только в управляемом приложении.

**Было:**

- Разработка ведётся в режиме «Управляемое приложение и обычное приложение». Всем клиентским модулям ставится флажок «Клиент (обычное приложение)». Код работает при любой настройке свойств конфигурации, которую 1С считает нормальной (требования «1С:Совместимо»). Так же используются инструкции препроцессора и заменяющие их функции.
- В чистой (не объединённой с типовой) конфигурации или расширении включено «Использовать управляемые формы в толстом клиенте в обычном режиме».
- Действия при старте системы отрабатывают в том числе в толстом клиенте обычного приложения.
