# 17. Прочее

[Оглавление](./README.md) | Назад: [16. Хранилище конфигурации](./16_storage.md) | Далее: [18. Стиль работы](./18_work_style.md)

Полезные практики, которые не вошли в другие главы.

- **17.1** Первичные данные, нужные для проведения и печати документа, в общем случае хранятся в самом документе, а не читаются из базы в момент проведения. Так результат проведения не зависит от того, что изменилось в справочниках после ввода документа.
- **17.2** Для каждого регламентного задания, запускаемого через консоль, заводится отдельный служебный пользователь. Имя пользователя отражает назначение задания.
- **17.3** Внешние подключения к базе (COM, веб-сервисы, HTTP-сервисы) выполняются под отдельными служебными пользователями. Имя пользователя показывает, откуда и зачем подключение.

<details><summary>Примеры</summary>

| Назначение | ❌ Плохо | ✅ Хорошо |
|---|---|---|
| Регламентное задание загрузки курсов валют | `Админ`, `Робот` | `РегламентЗагрузкаКурсовВалют` |
| HTTP-сервис для сайта | `web`, `Сервис` | `HTTPСайтЗаказы` |
| Обмен с WMS через COM | `Обмен` | `COMОбменWMSОстатки` |

</details>
